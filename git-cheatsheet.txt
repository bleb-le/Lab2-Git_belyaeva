!!! ШПАРГАЛКА ПО GIT !!!

1. НАСТРОЙКА И СОЗДАНИЕ
* git config --global user.name "Ник" - задать имя пользователя
* git config --global user.email "Почта" - задать email
* git init -b main - создать репозиторий с главной веткой main

2. БАЗОВЫЕ КОМАНДЫ
* git status - посмотреть состояние файлов (что изменено, что добавлено)
* git add . - добавить ВСЕ файлы в индекс (подготовить к коммиту)
* git add файл - добавить конкретный файл
* git commit -m "Текст" - сохранить изменения (сделать коммит)
* git log - показать историю коммитов (выход из просмотра - клавиша q)
* git log --oneline - показать историю в одну строку (кратко)
* git show ХЕШ - показать подробности конкретного коммита

3. ВЕТКИ
* git branch - показать список локальных веток
* git switch -c имя_ветки - создать ветку и переключиться на нее
* git switch имя_ветки - переключиться на существующую ветку
* git switch - - переключиться на предыдущую ветку
* git branch -d имя - удалить слитую ветку
* git branch -D имя - удалить ветку принудительно

4. РАБОТА С GITHUB (УДАЛЕННЫМ РЕПОЗИТОРИЕМ)
* git remote add origin URL - привязать локальный репозиторий к GitHub
* git remote -v - проверить привязку
* git push -u origin main - первый раз отправить код на GitHub
* git push - отправить изменения на GitHub
* git pull - скачать изменения с GitHub
* git fetch --prune - обновить список веток с сервера

5. РЕШЕНИЕ ПРОБЛЕМ
* Если терминал завис на двоеточии ":" -> нажмите клавишу q (английская)
* Ошибка "remote origin already exists" -> репозиторий уже привязан, проверьте через git remote -v
* Ошибка "no upstream branch" -> выполните git push --set-upstream origin имя_ветки
